## About

<br>

**doctorfill-dev** is an organization dedicated to building tools that give time back to healthcare professionals.

Doctors and medical staff spend countless hours on administrative tasks — filling forms, managing documents, navigating clunky software. We believe their time is better spent caring for patients.

That's why we create **small, focused, purpose-built tools** that solve real problems in medical workflows.

Everything we build follows these core values:

- **Secure by design** — On-premise first, no unnecessary data collection
- **Explainable** — Every decision can be traced and understood  
- **Reproducible** — Same inputs, same outputs, every time
- **Accessible** — Tools that anyone can use, regardless of technical skill
